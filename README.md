# 🪨 Rock, Paper, Scissors — Python

A classic Rock, Paper, Scissors game built using Python, where you play against the computer across multiple rounds and compete for the highest score.

## 📌 About the Project

This project is part of my Python learning journey. I built it to practice conditional logic, loops, random selection, user input handling, and score tracking by creating an interactive command-line game.

## 🎮 Game Rules

- **Rock** beats Scissors
- **Scissors** beats Paper
- **Paper** beats Rock
- If both choose the same option, it's a tie.

## ✨ Features

- Play multiple rounds
- Random computer choices
- Player vs. computer gameplay
- Score tracking for both players
- Tie detection
- Overall winner announcement
- Input validation
- Replay functionality

## 🛠️ Technologies Used

- Python
- VS Code
- `random` module

## ▶️ How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/python-rock-paper-scissors.git
   ```

2. Navigate to the project folder:

   ```bash
   cd python-rock-paper-scissors
   ```

3. Run the game:

   ```bash
   python rock_paper_scissors.py
   ```
